# kr-kit 공휴일 데이터 수동 검증 체크리스트

`@kr-kit/holidays-core`의 `src/holidays-data.ts`는 손으로 시드된 부분이 있다. publish 전, 그리고 데이터를 갱신할 때마다 아래를 사람이 한 번 확인한다.

## 자동 검증 (먼저)

- [ ] `pnpm test` — `holidays-cross-check.test.ts`(독립 패키지 `@hyunbinseo/holidays-kr`와 날짜 집합 대조) 통과
- [ ] `DATA_GO_KR_SERVICE_KEY=... pnpm verify:holidays` — 한국천문연구원 「특일 정보」 API와 불일치 0건. 임시공휴일/선거일 섹션이 의도와 일치하는지 콘솔 출력 확인
  - API 키: data.go.kr → 「한국천문연구원_특일 정보」(data.go.kr/data/15012690) 활용신청 → 일반 인증키(Decoding)

## 연도별 수동 스팟체크 (천문연 웹 / 위키백과 "대한민국의 공휴일"과 대조)

각 연도: ① 법정공휴일·국경일 누락 없음 ② 대체공휴일 발생일 정확 ③ 임시공휴일/선거일 정확.

- [ ] **2021** — 광복절(8/15 일)→8/16 대체, 개천절(10/3 일)→10/4 대체, 한글날(10/9 토)→10/11 대체. 현충일(6/6 일)은 대체 없음(대상 아님).
- [ ] **2022** — 대선 3/9, 지선 6/1. 추석 연휴 9/9~11 + 9/12 대체(9/11 일), 한글날(10/9 일)→10/10 대체.
- [ ] **2023** — 설날 1/21~23 + 1/24 대체(1/22 일), 부처님오신날(5/27 토)→5/29 대체(2023년 신설 규칙), 추석 9/28~30 + **10/2 임시공휴일**(끼인날).
- [ ] **2024** — 설날 2/9~11 + 2/12 대체(2/11 일), **국회의원선거 4/10**, 어린이날(5/5 일)→5/6 대체, 부처님오신날 5/15(수), 추석 9/16~18, **국군의날 10/1 임시공휴일**.
- [ ] **2025** — **1/27 임시공휴일**(설날 끼인날) + 설날 1/28~30, 삼일절(3/1 토)→3/3 대체, 어린이날·부처님오신날 둘 다 5/5 → 5/6 대체, **대통령선거 6/3**(보궐, 임시공휴일로 지정), 추석 10/5~7 + 10/8 대체(10/5 일). ⚠️ 2025-10-10은 임시공휴일이 **아니다**(초안엔 잘못 들어가 있었음 — 제거됨).
- [ ] **2026** — 설날 2/16~18, 삼일절(3/1 일)→3/2 대체, **노동절 5/1 공휴일**(2026 신규), 부처님오신날(5/24 일)→5/25 대체, 지선 6/3, 현충일(6/6 토)은 대체 없음, **제헌절 7/17 부활**(「공휴일에 관한 법률」 개정), 광복절(8/15 토)→8/17 대체, 추석 9/24~26, 개천절(10/3 토)→10/5 대체.

> 참고: 근로자의날(노동절, 5/1)은 2025년까지 「관공서의 공휴일에 관한 규정」상 공휴일이 아니어서 `holidays-core` 데이터에 없으나(`isKrxHoliday`로만 처리), 2026년부터 천문연 특일정보 API·`@hyunbinseo/holidays-kr` 모두 공휴일로 포함하므로 데이터에도 넣는다. `pnpm verify:holidays`가 2021~2026 전부 천문연 API와 일치함을 자동 확인한다.

## 갱신 절차

1. `DATA_GO_KR_SERVICE_KEY=... pnpm fetch:holidays` 로 `holidays-data.ts` 재생성
2. `pnpm build && pnpm test` — 회귀 없는지 확인 (실패 시 회귀 테스트 보강)
3. 임시공휴일/선거일이 API에 아직 없으면 `scripts/fetch-holidays.ts`의 `MANUAL_OVERRIDES`에 추가 후 재실행
4. 이 체크리스트 다시 통과 → 커밋
